Comments spanning lines must use comment/endcomment tags, never the hash form. Django's lexer matches the hash form with a non-DOTALL regex, so a multi-line one is not a comment at all -- its text is emitted verbatim into the email and any tag inside it really runs. {% endcomment %} {% firstof otp OTP_CODE as code %}
